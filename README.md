# Logos

知識と実行の仕組みを使って仕事を進め、その経験や新しい情報から、自身の知識・能力・構成を改善していくエージェント基盤。

主な利用窓口はCodexやClaude Codeなどでの対話とする。WebUIは、知識やタスク、接続プロジェクトを確認・操作するために、後から追加する拡張機能として扱う。

現在は新設計の段階であり、実装はまだない。

文章はMarkdown、プログラムは実装ソースを原本とする。両方に共通のオントロジー注釈を付け、知識・概念・判断基準・実装を関係として辿れるようにする。判断ロジックは通常のソースコードに実装し、説明や基準との関係を記述する。

- [初期版の設計](DESIGN.md)：本体と拡張の構造、利用と改善の流れ、実装順序。
- [文章・コード・オントロジーの設計](ONTOLOGY.md)：注釈の記法と対象範囲、共通グラフ、判断基準と実装の接続。

初期実装では、後から変更すると負担が大きい部分に先に配慮し、必要な機能が一周動くことを優先する。通常の利用は利用者とエージェントの善意を前提とし、知識の削除など、損失の大きい操作に保護を設ける。
